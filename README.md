### Hello Everyone! This Application is a Full Stack Application to Track the Status of each Training Assigned to a User.

## This app has two ways to login
1. User Login
2. Admin Login

## After User logs in , the user gets a dashboard which shows the trainings assigned to him/her.

## After Admin Logs in the Admin can see the Status of each user and Can Assign or delete trainings for any User.



### Tech Stack
1. .Net 8
2. Angular 21
3. SSMS 2022
